# LittleGame 小游戏合集 🎮

单文件 HTML5 小游戏合集，双击即玩，无需服务器、无外部依赖（Canvas 手绘美术 + WebAudio 合成音效）。

## 🏮 同福客栈（主打）

《武林外传》主题客栈经营游戏——你是掌柜佟湘玉，在七侠镇把同福客栈经营成天下第一楼。

**打开方式**：双击 `同福客栈.html`（推荐 Chrome / Edge）

### 玩法

- 点击门口排队客人带位入座（雇小贝后有空桌客人自动入座，双人桌可拼桌）
- 客人举"!"时点击下单，李大嘴自动开炒；出菜口的菜点击端起（一次最多3盘），再点客人上菜
- 吃完桌上留银两，点击收钱；客人耐心（红心）耗尽会生气离店
- 8秒内连续上菜触发连击，小费越连越高

### 内容一览

| 系统 | 内容 |
|---|---|
| 主线 | 20 天关卡，剧情递进，第 20 天"武林大会"终局 |
| 员工 | 白展堂/郭芙蓉/祝无双/莫小贝/吕秀才/小米/邢捕头/白三娘——8 位 AI 员工各司其职（跑堂/迎宾/拉客/小费光环），每人 5 级专属特训 |
| 客人 | 丐兄/镖师/燕小六/赛貂蝉/钱夫人/平谷一点红/莫小贝/吕秀才/娄知县，9 种脾气与消费习惯 |
| 菜品 | 10 道基础菜 + 8 道研发新菜（每晚可让李大嘴研制，正负效果混合） |
| 店外街道 | 拉客/贵客/小贩卖食材；还有小偷出没，连点 3 下抓贼 |
| 镇上夜市 | 每晚打烊后：十八里铺淘金（赌运气）、七侠镇事件（明日 buff）、包席预约（15 人大席）、大嘴研发新菜、大厅扩建 |
| 掌柜技能 | 鼓舞士气（全员提速+客人耐心回升）、葵花点穴手（冻结客人耐心）、快进 1~5 倍 |
| 无尽模式 | 通关后解锁（或首页直入赠启动资金）：每 2 分钟过一天、难度随天数永久增长、累倒后收入入账整备再战 |

### 操作

- 鼠标/触屏点击；`P` 暂停 · `M` 静音 · `F` 快进 · `R` 鼓舞
- 进度（最高纪录/成就/静音设置）自动保存在浏览器本地
