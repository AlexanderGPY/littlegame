# LittleGame 小游戏合集 🎮

单文件 HTML5 小游戏合集，双击即玩，无需服务器、无外部依赖（Canvas 手绘美术 + WebAudio 合成音效）。

## 🏮 同福客栈（主打）

《武林外传》主题客栈经营养成游戏——你是掌柜佟湘玉，在七侠镇把同福客栈经营成天下第一楼。

**打开方式**：双击 `同福客栈.html`（推荐 Chrome / Edge）

### 核心玩法：经营养成（无天数上限）

- 点击门口排队客人带位入座（雇小贝后有空桌客人自动入座，双人桌可拼桌）
- 座位上摆**茶壶+「客」字牌** = 已有客人正走向这座（高峰期门口人潮都是"正在入座"，不是干等）
- 客流随经营天数持续增长（第30天后进店间隔低至1.3~2.0秒），名气与「门前吆喝」再叠乘；后期满配可真正坐满40座（4列×5行共20桌）
- 客人举"!"时点击下单，李大嘴自动开炒；出菜口的菜点击端起，再点客人上菜
- 吃完桌上留银两，点击收钱；客人耐心（红心）耗尽会生气离店
- 8 秒内连续上菜触发连击，小费越连越高
- **没有通关天数与失败目标**：每天打烊结算收入，存入钱柜继续经营

### 每日安排：经营 or 游历

- 每天清早二选一：**🔔 开张经营**（手动玩一天）或 **🐎 外出游历**
- **第 10 天起**才可外出游历；**8 个江湖地点**随经营天数陆续解锁，行程与盘缠各不相同（游历为全画面手绘行旅场景：每个地点有专属天色/远景/路途，掌柜骑马赶路，多天行程还会由昼入暮）：

| 地点 | 天数 | 盘缠 | 解锁 |
|---|---|---|---|
| 七侠镇周边 | 1天 | 免费 | 第10天 |
| 左家庄 | 1天 | 15两 | 第10天 |
| 西凉河 | 1天 | 10两 | 第11天 |
| 十八里铺 | 2天 | 40两 | 第13天 |
| 衡山 | 3天 | 90两 | 第17天 |
| 汉中 | 4天 | 160两 | 第24天 |
| 京城 | 5天 | 300两 | 第34天 |
| 西域 | 6天 | 500两 | 第49天 |

- 每个游历日触发 2~3 张事件卡，共 30+ 个事件：奇遇、剧情、挑战应有尽有，**奖励与处罚随机**
- **文比 / 武比 / 厨艺挑战**：胜率由队伍属性决定——武力看白展堂/小郭/无双/邢捕头/三娘/小贝，文采看吕秀才与菜单，厨艺看李大嘴与新菜研发（商铺雇人与特训直接提升游历胜率，落败可能受伤：次日全员速度-15%）
- 事件奖励：银两、名气（永久客流+2%/点）、新菜谱、明日 buff；处罚：被劫、赌输、受伤
- 京城可**拜见食神诸葛孔方**（大嘴的师父）：厨艺讨教赢了传绝活+新菜
- **第 30 天解锁挂机经营**：游历期间店里按昨日收入（±10%）×行程天数自动入账
- 集齐全部七个地点解锁成就「游遍江湖」

### 升级系统：人人可升级

| 类别 | 内容 |
|---|---|
| 桌椅 | 单人桌 → 双人桌（可拼桌）→ 红木雅座（小费+10%、耐心+15%），桌子左右各配方凳 |
| 设施 | 新菜刀×5、灶台扩建×3（最多5口）、装修×5、招牌×5、**门前吆喝×5（客流+12%/级）**、菜单×5、双层食盒×2（最多端4盘）、薪酬激励×5 |
| 员工 | 白展堂/郭芙蓉/祝无双/莫小贝/吕秀才/小米/邢捕头 7 位 AI 跑堂，各 5 级专属特训；**就近认领任务、干完活原地驻场待命**，不空跑 |
| 后厨 | **孔小方**（食神诸葛孔方门下学徒）：做菜+15%、出菜口扩到 12 格，颠勺练习×5（做菜再+10%/级） |
| 大厅 | 夜市扩建×3，每级每天多 3 张桌 |

### 建模

- 人物整体比例缩小（约 0.75×），桌椅放大，人/桌/店比例更协调
- 双人桌左右各一把方凳；客人有落座动画，坐姿（腿搭凳上、手臂搭桌）、吃饭晃腿、起身离店

### 操作

- 鼠标/触屏点击；`P` 暂停 · `M` 静音 · `F` 快进 · `R` 鼓舞 · **`L` 运营诊断**
- **运营诊断（L 键或 📊 按钮）**：实时判定卡点——客流积压 / 接单慢 / 灶台产能 / 端菜慢 / 收钱不及时，附 1 分钟滚动指标（排队、等灶订单、出菜口积压、接单与上菜耗时 p95）和异常事件日志
- **切换页面/失焦不暂停**：切走后游戏按真实时间照常营业（打烊、游历翻牌都会推进），回来即见结果
- 进度（最高纪录/成就/静音设置）自动保存在浏览器本地
